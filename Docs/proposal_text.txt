Proposed Research Project Details:
1. Working Title
Augmented Reality–Based Interior Design Mobile Application for Wall & Floor Color
Visualization with Personalized Color Palette Recommendation
2. Problem Statement
Interior design decisions, especially regarding wall and floor colors, are often challenging
for homeowners and designers because colors look different in reality than in catalogues or
design boards. Customers usually struggle to imagine how a selected color would appear in

Undergraduate Research Proposal Form, Faculty of Information Technology [Version 10/06/2024]

their actual space, leading to costly mistakes and dissatisfaction. Traditional 2D color
samples do not provide realistic visualization, while hiring professional designers can be
expensive. At the same time, color harmony and personalized design preferences are rarely
addressed by existing tools. Therefore, there is a need for a mobile application that leverages
Augmented Reality (AR) to allow real-time visualization of wall and floor colors, while
also providing intelligent color palette recommendations based on user preferences. Such
a solution would save time, reduce cost, and improve customer satisfaction by enabling datadriven and personalized design decisions.
3. Research Aim
To design and develop an Augmented Reality–based mobile application that enables
real-time visualization of wall and floor colors and recommends personalized color palettes
based on user preferences, enhancing decision-making in interior design.
4. Research Objectives
Objective 1: To implement an AR-based feature that allows users to visualize selected
wall and floor colors in real-time using their smartphone camera.
Objective 2: To design a color recommendation system that generates personalized color
palettes based on user input and established design principles.
5. Research Questions
Question 1: How can AR technology be applied to accurately visualize wall and floor colors
in real-world environments?
Question 2: What methods can be used to generate personalized and aesthetically pleasing
color palettes based on user input?
Question 3: To what extent does the proposed app improve decision-making and satisfaction
compared to traditional color selection methods?
6. Background Literature Review
Interior design applications have increasingly incorporated technology to improve
visualization and decision-making. Augmented Reality (AR) has been widely studied for

Undergraduate Research Proposal Form, Faculty of Information Technology [Version 10/06/2024]

its ability to project virtual elements into physical spaces. Houzz and IKEA’s AR apps
demonstrate how users can preview furniture and colors in real environments, though these
are limited in personalization. Research by Emersya (IEEE Spectrum, 2022) highlights how
AR enables consumers to customize products, reinforcing the need for similar solutions in
interior design.
Wall and floor color visualization remains a key challenge. According to Automatic Interior
Design in AR Based on Procedural Rules (ResearchGate, 2021), AR can automatically adapt
interior layouts, while Background-Aware Colorization in AR (ResearchGate, 2022)
emphasizes the importance of harmonizing colors with environmental factors.
Personalization in interior design has been explored in studies like Interactive Interior
Design Recommendation via Multimodal Reinforcement Learning (ArXiv, 2023), which
uses AI to align design with user feedback. Similarly, Aesthetic Preference Prediction Using
Fuzzy Logic (ArXiv, 2024) demonstrates how computational models can predict human
color preferences.
Color harmonization is another focus area. Color Harmonization in AR Applications (MDPI,
2021) discusses how visual balance impacts user experience, directly aligning with this
project’s recommendation system.
Despite these advances, most existing solutions treat visualization and recommendation as
separate problems. Few combine AR visualization with intelligent personalization,
leaving a gap for a system that both shows how colors look and recommends palettes tailored
to user needs. This project fills that gap by integrating AR visualization with an AI-driven
recommendation system, offering a comprehensive solution.
Thus, the research builds upon existing AR visualization and AI-based recommendation
systems but innovates by combining them into a unified, user-friendly mobile app for interior
design.

7. Data Requirement

Primary Data
1. User Surveys (Example: Google Forms or in-app questionnaire)
○ Surveys can ask users about their favorite colors, preferred wall–floor
combinations, lighting conditions at home, and overall design preferences.
○ Why: This helps the recommendation system learn real user preferences
instead of relying only on theory.
2. User Testing of the Prototype (Example: Asking 10–15 users to try the app and
give feedback)
○ Users interact with the AR prototype, test wall and floor color visualization,
and then rate usability, realism, and satisfaction.
○ Why: This evaluates whether the app is user-friendly and if the
recommendations feel practical and realistic.
Secondary Data
1. Existing Datasets on Color Theory and Palette Combinations (Example:
Adobe Color CC database, COCO color dataset)
○ These provide predefined harmonious color palettes (complementary,
triadic, analogous, etc.).
○ Why: The recommendation system can suggest scientifically proven color
matches instead of random combinations.
2. Published Research on AR Visualization Techniques (Example: IEEE papers
on AR interior design)
○ Previous studies give insights into best practices for AR rendering,
environmental lighting effects, and realism in visualization.
○ Why: Helps improve the accuracy and performance of the AR module.
